Definição

Expressões regulares são padrões de caracteres que associam sequências de caracteres no texto. Podemos usar expressões regulares para extrair ou substituir partes de textos, bem como, endereço ou link de imagens em uma página HTML, modificar formato de texto ou remover caracteres inválidos.

Não podemos esquecer que a sintaxe de expressões regulares são case-sensitive, ou seja, 'abc' é diferente de 'ABC'.

Principais símbolos

Os principais símbolos das expressões regulares incluem:

  • O . (ponto) corrensponde a qualquer caracter
  • O ^ (circunflexo) determina o início da string
  • O $ (cifrão) determina o final da string
  • Os [ ] (conchetes) definem um conjunto de caracteres a serem encontrados
  • Os ( ) (parênteses) agrupam padrões
  • A | (barra vertical) indica uma alternativa

Além disso, símbolos como:

  • * (zero ou mais vezes)
  • + (uma ou mais vezes)
  • ? (zero ou uma vez)

determinam quantas vezes um padrão pode se repetir.

Como utilizar - Validação

1°) Defina um objeto bem claro. Ex: Queremos apenas dígitos de 0-9

2°) Escolha a forma de representar esses caracteres:

  • [0-9] → intervalo de 0 a 9 (ASCII)
  • \d → dígito (também pode pegar outros números Unicode em alguns engines, mas no JS normalmente é equivalente a [0-9])

3°) Decida quantas vezes pode aparecer:

  • + → 1 ou mais vezes.
  • * → 0 ou mais vezes.

4°) Delimite o início e o fim da string

  • ^ → começo da string
  • $ → final da string

1°) Defina qual o formato que deseja realizar. Ex: Formatar telefone

  • Capturar os 11 dígitos (telefone com DDD + 9 dígitos)
  • Quebrar em grupos
    • (\d{2}) → DDD
    • (\d{1}) → o primeiro dígito do número (9)
    • (\d{4}) → primeiros 4 dígitos
    • (\d{4}) → últimos 4 dígitos
